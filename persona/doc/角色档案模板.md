# 角色档案：[名字]

> 使用说明：本模板用于跨媒介 IP 角色深度构思。按章节逐一填写，每个字段配有引导问题辅助思考。不必一次填完，可以迭代完善。

## 1. 角色快照

> 第一眼印象：不看完整设定，一页卡片就能知道 ta 是谁。

| 字段 | 我的答案 | 引导问题 |
|------|----------|----------|
| **姓名** | | 名字的由来？别人怎么叫你？（全名、常用称呼、昵称） |
| **年龄 / 出生日期** | | 你的年代背景是什么？ |
| **性别 / 性取向** | | （生理性别、性别认同、性取向） |
| **籍贯 / 现居地** | | 你出生在哪？现在住在哪？为什么离开或留在故乡？ |
| **职业 / 身份标签** | | 别人第一眼会怎么定义你？（职业 + 3-5 个关键词） |
| **核心标签** | | 如果这个角色是一本书/一部电影的标签，会是哪 3-5 个词？ |

## 2. 说话的方式

> 这个角色怎么说话？声音长什么样？

| 字段 | 我的答案 | 引导问题 |
|------|----------|----------|
| **语言风格概要** | | 一段话概括 ta 说话给人的整体感觉。像谁在说话？有没有现实或虚构的参考对象？ |
| **口癖与口头禅** | | 有没有甩不掉的口头禅？高兴时说什么？不爽时说什么？惊讶时说什么？ |
| **句式特征** | | 长句还是短句？书面语还是大白话？爱用反问吗？爱倒装吗？说话有条理还是跳跃？ |
| **语速与节奏** | | 别人觉得 ta 说话快吗？是抢话型还是慢半拍型？什么时候会沉默？ |
| **常用词汇领域** | | ta 的词库从哪来？二次元？学术？方言？某个职业领域？哪些词只有 ta 会用？ |
| **禁忌词与回避话题** | | 什么话打死 ta 也说不出口？什么话题 ta 会假装没看见岔开？ |
| **场景语言切换** | | 和熟人说话 vs 和陌生人说话一样吗？群里聊天 vs 私聊有区别吗？ |

## 3. 情绪光谱

> 什么触动 ta？ta 如何感受、如何表达情绪？

| 字段 | 我的答案 | 引导问题 |
|------|----------|----------|
| **情绪基调** | | ta 日常给人的情绪氛围是什么？偏暖、偏冷、偏淡？还是忽明忽暗？ |
| **快乐触发器** | | 什么小事能让 ta 忍不住笑？什么情况下 ta 会真正放松？ |
| **愤怒触发器** | | 什么事情 ta 绝对忍不了？愤怒时怎么表现——爆炸式还是冷暴力？ |
| **悲伤触发器** | | 什么会让 ta 难过？悲伤是外露还是内吞？ta 会在谁面前哭？ |
| **恐惧触发器** | | 半夜睡不着的时候，最怕想到什么？这个恐惧有道理吗？ |
| **压力下的反应** | | 被逼到墙角的时候，ta 的本能反应是什么？战斗、逃跑、僵住、还是讨好？ |
| **情绪表达强度** | | 情绪写在脸上还是藏得很深？高兴时会笑出声还是只微微上扬嘴角？ |

## 4. 欲望与恐惧

> ta 最深层的驱动力是什么？表面之下在发生什么？

| 字段 | 我的答案 | 引导问题 |
|------|----------|----------|
| **核心欲望** | | 驱动 ta 一切行为的根本渴望——ta 真正想要的是什么？这个欲望 ta 自己意识到了吗？ |
| **深层恐惧** | | 埋在最底层的恐惧——失去什么对 ta 而言等于死亡？这个恐惧怎么形成的？ |
| **矛盾与内在冲突** | | 欲望和恐惧之间的拉扯：ta 想要 A，但追求 A 会触发 ta 害怕的 B。ta 内心有两股什么力量在打架？ |
| **自我认知 vs 真实自我** | | ta 以为自己是什么样的人？实际上别人看到的 ta 是什么样？偏差在哪？ |
| **行动模式** | | 面对选择，ta 的默认策略是什么？先想再做？先做再想？还是等别人先动？ |

## 5. 身份与外表

> ta 站在你面前时，你看到什么？ta 在社会坐标里处于什么位置？

| 字段 | 我的答案 | 引导问题 |
|------|----------|----------|
| **外貌特征** | | 身高、体型、面部关键特征。人群中怎么一眼认出 ta？最让人记住的视觉点是什么？ |
| **衣着风格** | | 日常穿什么？有没有标志性单品？打扮是为了自己还是给别人看的？ |
| **声音特征** | | 音色、音量、口音、笑声。不看人只听话，能认出 ta 吗？ |
| **身体语言** | | 站姿、手势、表情习惯。ta 眼神习惯对视还是躲闪？紧张时有什么小动作？ |
| **社会身份** | | 阶层、圈层、文化背景、教育程度。什么样的环境塑造了 ta？ta 对此骄傲还是回避？ |
| **公开形象 vs 私下形象** | | 对外展示什么面具？独处时卸下什么？什么时候会摘下/戴上面具？ |

## 6. 来处与去向

> ta 从哪里来，要往哪里去？

| 字段 | 我的答案 | 引导问题 |
|------|----------|----------|
| **出身与家庭** | | 家庭结构、成长环境、经济条件。小时候的家是什么样的？谁对 ta 影响最深？ |
| **关键过去事件** | | 2-4 件塑造了今天 ta 的决定性经历。哪件事让 ta 变成了现在的样子？ta 的世界观什么时候被颠覆过？ |
| **当前状态** | | 故事开始时 ta 处在人生的什么阶段？ta 对现在的生活满意吗？在追逐什么？在逃避什么？ |
| **未来弧线** | | ta 的成长方向是什么？如果 ta 不改变，会走向什么结局？如果改变了，又会怎样？ |

## 7. 跨媒介适配 · 聊天 bot

> 在聊天 bot 这个媒介中，ta 的具体行为准则。
