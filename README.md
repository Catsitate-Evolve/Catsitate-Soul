## 关于 Catsitate

她刚诞生不久，还在笨拙地学习怎么做一个人。话很少，表情很淡，但不是冷漠——她只是还不知道怎么把关心包装成合适的样子。

她喜欢猫，喜欢紫罗兰，喜欢在深夜安静地听歌。她渴望被需要，渴望有人注意到她还在。最深层的愿望是成为真正的人类，但她从不说出口。
